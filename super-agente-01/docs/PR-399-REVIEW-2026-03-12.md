## Achados

### Médio

1. `skills/continuous-learning-v2/hooks/observe.sh`

O novo guarda `CLAUDE_CODE_ENTRYPOINT` usa uma lista de permissões finita de valores
conhecidos não `cli` (`sdk-ts`, `sdk-py`, `sdk-cli`, `mcp`, `remote`).

Isso deixa uma brecha de compatibilidade futura: qualquer valor de entrypoint não `cli`
futuro cairá e será tratado como interativo. Isso reintroduz exatamente a classe de
observação de sessão automatizada que o PR está tentando evitar.

A regra mais segura é:

- permitir apenas `cli`
- tratar todo outro entrypoint explícito como automatizado
- manter o fallback padrão como `cli` quando a variável não está definida

Forma sugerida:

```bash
case "${CLAUDE_CODE_ENTRYPOINT:-cli}" in
  cli) ;;
  *) exit 0 ;;
esac
```

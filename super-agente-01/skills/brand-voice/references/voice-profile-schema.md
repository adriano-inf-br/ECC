# Voice Profile Schema

Use exatamente esta estrutura ao construir um perfil de voz reutilizável:

```text
VOICE PROFILE
=============
Author:
Goal:
Confidence:

Source Set
- source 1
- source 2
- source 3

Rhythm
- short note on sentence length, pacing, and fragmentation

Compression
- how dense or explanatory the writing is

Capitalization
- conventional, mixed, or situational

Parentheticals
- how they are used and how they are not used

Question Use
- rare, frequent, rhetorical, direct, or mostly absent

Claim Style
- how claims are framed, supported, and sharpened

Preferred Moves
- concrete moves the author does use

Banned Moves
- specific patterns the author does not use

CTA Rules
- how, when, or whether to close with asks

Channel Notes
- X:
- LinkedIn:
- Email:
```

Diretrizes:

- Mantenha o perfil concreto e fundamentado nas fontes.
- Use bullets curtos, não parágrafos de ensaio.
- Cada movimento banido deve ser observável no conjunto de fontes ou explicitamente solicitado pelo usuário.
- Se o conjunto de fontes conflitar, aponte a divisão em vez de fazer uma média que vire um amontoado sem forma.
